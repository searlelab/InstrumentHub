# InstrumentHub user guide

Sign in with your individual account. The calendar opens to **All instruments**, a compact monthly overview: each instrument has a shaded track, and morning, afternoon, and overnight blocks use sun/moon icons. Hover a block for its instrument, status, booking, and handler details. Click and drag across open blocks on one instrument to select and hold time directly from the overview; use the instrument selector when you want that instrument's detailed calendar. State colors and patterns distinguish confirmed, tentative, active, paused, maintenance, outage, and temporarily held time.

To book, select available fixed blocks and begin the hold. The held blocks define the duration, so no injection count or time estimate is required. Choose the PI, project, optional grant, experiment name, and sample category before the countdown expires. Projects narrow to the selected PI and grants narrow to the selected project. If a PI, project, or grant is missing, create it directly in the booking form; newly created projects are added to your profile and all additions are audited. A PI or project created by a member is validated through administrator review of its first booking, so that booking remains tentative until approved; later bookings can use the validated reference normally.

Sample category describes the sample matrix and sensitivity—for example, high-load liver or low-input single-cell material. Administrators use it to sequence runs and reduce contamination or carryover; it is not a billing category. Optional run details include gradient length, column setup, libraries, a description, and scheduler notes.

A compliant request confirms immediately. Rule exceptions automatically remain tentative while protecting their slots. Use **Request administrator review** only when you knowingly need an exception or have a special circumstance the automatic checks cannot represent; explain the situation in scheduler notes so an administrator can decide.

Open a booking to see its schedule, handler, authenticated-member contact details, and status. Owners may edit or cancel eligible future tentative or confirmed bookings. Contact an administrator for active, paused, completed, rejected, historical, or administratively changed bookings.

Use Inbox to review booking confirmations, approval decisions, cancellations, and applied schedule changes. The calendar identifies the currently scheduled instrument handler and their authenticated-member contact details; it explicitly says when nobody is currently scheduled.
